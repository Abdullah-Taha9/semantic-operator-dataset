# Ground-Truth Labels

## Dataset Summary

This dataset contains {{N_ROWS}} source rows with silver-standard boolean labels
generated by a large language model under several documented queries.

## Dataset Structure

- `{{BASE_FILENAME}}` is the pristine, unlabeled base dataset.
- `{{MERGED_FILENAME}}` is the flat dataset with all selected label columns. Use this
  file unless you specifically need the per-query audit trail.
- `{{LABELS_DIRNAME}}/` contains the provenance manifest and raw checkpoint fragments.

## Which column is which query

{{QUERY_TABLE}}

Null values mean the model returned a response that could not be parsed as exactly
`True` or `False`. They do not indicate missing row coverage.

## Dataset Creation

Labels were generated with `ground-truth-labeler`. The per-query table above combines
reporting-only type/category notation from the query JSONL with the labeling manifest,
which records the model, prompt, generation date, configuration fingerprint, and
base-dataset identity.

The labels are silver-standard model judgments and may contain errors or biases. Review
their suitability before using them as evaluation targets.
